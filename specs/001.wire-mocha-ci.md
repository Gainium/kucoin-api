# 001 — Wire mocha and CI to a repo with no tests

## §1. Behaviour today

No test files. `package.json`'s `"test"` script is the default npm
placeholder (`echo "Error: no test specified" && exit 1`) — it fails on
any invocation, which is worse than absent: a CI job that ran `npm test`
today would always be red regardless of code changes (§1.1). No CI
workflow beyond `dco.yml` (sign-off only) exists (§1.2).

## §2. Desired behaviour

`npm test` runs a real mocha suite and exits 0 (§2.1). CI runs `npm
test` on every PR (§2.2). One placeholder spec proves the wiring is real
until actual coverage lands (§2.3).

## §3. Open questions / assumptions

- §3.1 mocha + chai, per this task's brief — same pattern as the sibling
  "no tests yet" repos wired in this sweep. Pre-authorized, not left
  open.
