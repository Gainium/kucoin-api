# 001 — Wire mocha and CI to a repo with no tests

## Build order

1. Add devDependencies: `mocha`, `chai`, `@types/mocha`, `@types/chai`,
   `ts-node` (not currently a devDependency here — this repo only
   `tsc`-builds; needed to run `.ts` specs under mocha).
2. Add `test/placeholder.spec.ts`.
3. Replace the failing default `"test"` script with a real mocha
   invocation over `test/**/*.spec.ts` via `ts-node/register`.
4. Add `.github/workflows/test.yml`: PR + push to `master` (this repo's
   default), Node 22, `npm ci`, `npm test`.
5. Verify `npm test` green locally.

## Blast radius

1. Other call sites: none — new file. The replaced `"test"` script was
   never invoked by anything else in this repo (`build`/`lint` don't
   call it).
2. `core/` submodule: none in this repo.
3. CLAUDE.md contracts: this repo is imported by `exchange-connector`'s
   `core` — a devDependency/test-script change doesn't affect the
   published library surface consumers import.
4. Other tests: none exist yet.
